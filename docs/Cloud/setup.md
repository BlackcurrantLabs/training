# Environment Setup

## Checklist

- Install a Linux environment - WSL2 + Ubuntu on Windows, or the built-in Terminal on macOS (already Unix-based).
- Install [VS Code](https://code.visualstudio.com/).
- Create a GitHub account.
- Install Git and set your identity (`user.name` / `user.email`).
