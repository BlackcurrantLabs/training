# Python for Automation

## Topics

- File handling and error handling (`try` / `except`)
- Working with APIs: the `requests` library, reading/writing JSON
- OOP basics: classes, and when you actually need them
- Virtual environments (`venv`) and `pip`
- Reusable functions, splitting code into modules, basic regex
- Running shell commands from Python (`subprocess`), reading CLI arguments (`argparse`)

## How to learn

**Python** - [CS50P: Introduction to Programming with Python](https://cs50.harvard.edu/python/) (Harvard, free on edX/YouTube) - covers these topics in depth.

## How to practice

Write one small script a day: a file organizer, a web scraper, a CLI weather tool, a password generator, a bulk file renamer.
