# Databases (SQL)

## Topics

- Relational concepts: tables, rows, columns, primary/foreign keys
- SQL: `SELECT`, `WHERE`, `JOIN`, `GROUP BY`, `INSERT`, `UPDATE`, `DELETE`
- NoSQL, conceptually - when you'd reach for MongoDB/DynamoDB instead
- Indexes and transactions (ACID) - conceptually, why they matter
- Connecting Python to Postgres (`psycopg2`)
- Basic backup concepts

## How to learn

- [SQLBolt](https://sqlbolt.com/) - free, interactive, in-browser exercises.
- [PGExercises](https://pgexercises.com/) - Postgres-specific practice, plus the [official PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html) for setup.

## How to practice

3-4 SQL exercises daily until querying feels natural rather than effortful.
