# Programming Logic & Git

## Linux

Linux command-line skills are required before continuing. See [Linux and Command Line Basics](../Foundations/linux-cli.md).

## Topics

- Programming logic: variables, data types, conditionals, loops, functions, lists, dictionaries
- Git basics: `init`, `add`, `commit`, `push`, `pull`, `clone`, `status`, `log`, `diff`, branches (`checkout -b`), merging and resolving conflicts, `.gitignore`
