# CI/CD & Git Workflows

## Topics

- Git in a team: pull requests, code review, working across multiple branches
- CI/CD concepts: build -> test -> deploy stages
- GitHub Actions - free and integrated with GitHub, a good starting point
- Storing secrets (API keys, tokens) in GitHub Actions instead of the repo
- Basic automated testing with `pytest`
- Reading pipeline logs and fixing a broken pipeline

## How to learn

- [GitHub Skills](https://skills.github.com/) - free, official, includes a course on GitHub Actions.
- [GitHub Actions Documentation](https://docs.github.com/en/actions)

## How to practice

Add a GitHub Actions workflow to an existing project: run tests automatically on every push, then build the Docker image automatically if tests pass.
