# Kubernetes II - Operations

## Topics

- Namespaces, resource requests/limits
- Ingress and cluster networking basics
- Persistent Volumes for stateful apps (like a Postgres database)
- Helm - the Kubernetes package manager
- RBAC and ServiceAccounts - who's allowed to do what in a cluster
- Troubleshooting: `CrashLoopBackOff` pods, unreachable services, reading Events

## How to learn

- Continue with [KodeKloud](https://kodekloud.com/courses/) and the [official Kubernetes docs](https://kubernetes.io/docs/home/).
- Optional certification: **CKAD** (Certified Kubernetes Application Developer) fits this track better than CKA, which leans toward cluster administration.

## How to practice

Same daily habit as before - deploy, break, fix, on a local cluster.
