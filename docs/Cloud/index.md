# Cloud / DevOps Engineering

This track covers programming fundamentals through deploying and operating real infrastructure on the cloud - the core skill set for Cloud Engineer, DevOps Engineer, and SRE roles.

## Prerequisites

- Comfortable with basic computer usage and working primarily from a terminal.
- No prior programming experience required.

    1. [Environment Setup](setup.md)
    2. [Programming Logic & Git](foundations.md)

    6. [Databases (SQL)](databases.md)
    7. [Docker & Containers](docker.md)

!!! note "Why Python"
    Python is the one language used throughout this track, for scripting and automation - AWS's SDK (`boto3`) is Python-first, and it's a common choice for automation tooling generally. Go is worth learning later - Docker, Kubernetes, and Terraform are all written in it - but it isn't required to start or finish this track.

## Core skills you'll build

- Programming logic and debugging
- Version control with Git
- Linux command-line proficiency
- Networking fundamentals
- Relational databases (SQL)
- Automated testing
- Containerization and orchestration
- Infrastructure as Code
- Monitoring and incident response
- Security fundamentals
