
# Manual Testing Practice - The Overview

This practice section consists of hands-on manual testing exercises designed by senior QA professionals to help beginners develop practical testing skills using real-world demo applications. These exercises enable learners to execute predefined test cases, observe application behavior, identify defects, and build a strong foundation in manual testing.

In addition to the test cases, this section also includes dedicated testing challenges that focus on specific QA concepts such as input validation, security testing, boundary and edge case validation, and test data generation.

The documentation provided throughout this section contains test cases written in different formats and styles, exposing learners to various approaches and industry practices for documenting test scenarios. Each exercise also includes links to the corresponding website, allowing learners to execute the test cases independently and validate the application from their own perspective.

The primary objective of this practice section is not only to provide real-world exposure to demo and intentionally buggy websites but also to encourage exploratory testing. While several sample defects are documented, many issues have been deliberately left undisclosed so that learners can discover, reproduce, document, and report them on their own.

By working through these exercises, learners will gain experience in identifying functional defects, UI inconsistencies, usability issues, and edge cases. The websites included in this section are specifically chosen to strengthen analytical thinking, improve test case writing skills, and develop the QA mindset required to perform effective Smoke Testing, Sanity Testing, Regression Testing, and Exploratory Testing in real-world projects.
